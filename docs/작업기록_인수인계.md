## 2. 화면 기능
- 기간: 1주/2주/3주/1달/2달/3달/6개월/배포 후~현재, 직접 선택. 주는 월~일, 달은 1일~말일

- 채널별(맞춤 채널 그룹) 카드·차트·표
- 📝 분석 노트: "Claude용 복사" → Claude 대화창에 붙여넣어 분석 → 결과를 붙여넣어 저장 (페이지·기간별, 팀 공유, API 비용 없음)

## 3. 구조
- `site/index.html` 화면 전체 (Chart.js)
- `api/config.js` 페이지·배포일 저장 / `api/data.js` GA4 조회 / `api/totals.js` 순 사용자 / `api/analyze.js` 분석 노트 저장
- `api/_lib/` ga4.js(GA4 REST·서비스 계정 JWT), metrics.js(지표 정의), seed.js(기본 제품·페이지), config.js, store.js(Upstash Redis), http.js
- `middleware.js` Google 로그인 + API 보호
- 배포: GitHub Actions 가 push 때 Vercel 에 배포 (Vercel 의 Redeploy 버튼은 안 됨 → 환경 변수 바꾸면 새로 push)
- `.claude/hooks/auto-commit.sh` Claude Code 가 파일을 고치면 자동 커밋(푸시는 안 함)
